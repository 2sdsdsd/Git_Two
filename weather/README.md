# 小刘同学的天气查询系统 · 第二版

可爱俏皮的天气小屋：糖果配色、笑脸云朵、贴纸手账、专属关心话和整页气象画布。保留 138 个内置地点、在线地名搜索、收藏、24 小时与 7 天预报。

## 使用

电脑双击 `启动本地天气.cmd`；手机通过电脑上的 `启动公网访问.cmd` 获取 HTTPS 网址，可用流量或任意 Wi-Fi。详细步骤与启动变化见 `使用说明.txt`。

本机应用控制拦截了新编译的未签名 EXE，第二版改为使用附带的官方签名 Node 程序运行，CMD 入口文件名继续沿用。无需另外安装依赖。请保持整个项目文件夹完整。第一版备份见 `versions/第一版.zip`。

## 第二版功能

- 每次查询后显示一句结合天气、体感温度和风速的关心话，可点击「再关心一句」更换；由本地规则生成，无需模型账号或密钥。
- 整页与卡片均区分晴天、阴天、雾、毛毛雨、小雨、中雨、大雨/暴雨、雷雨、小雪、中雪、大雪以及城市昼夜。
- 大雨、大雪增加粒子数量、大小或速度；风速和风向影响风线、云朵与雨雪偏移。
- 动效开关、系统减少动态效果、后台暂停；手机降低粒子数量。
- 请求失败不生成虚假天气，缓存与对应关心话会明确标注；兼容第一版收藏。

## 开发

`src/index.html` 页面结构，`src/styles.css` 基础布局，`src/playful.css` 可爱风格，`src/atmosphere.js` 全屏天气，`src/app.js` 查询与关心话，`src/cities.js` 城市数据。

`server/server.cjs` 是独立服务，提供固定天气接口代理、限流与缓存，通过 Windows 自带网络组件兼容系统代理。没有任意网址代理或文件系统访问接口。

修改后运行 `tools/runtime/node.exe tools/build.js` 生成 HTML 与 `web/index.html`，再重启服务。启动程序需要 `tools/runtime/`、`server/` 与 HTML 文件。

## 数据与公网

数据来自 [Open-Meteo](https://open-meteo.com/)，当前天气为模型估算，预报与生活建议仅供参考。风渲染取当前风速、风向，不表示全天风力恒定。

Cloudflare 临时通道需要电脑开机联网，重新启动通常更换网址，不保证可用性。`web/` 可用于后续长期静态部署；长期部署后无需电脑运行，可按托管平台网络情况添加代理。

附带运行程序由 OpenJS Foundation 签名，许可证见 `tools/runtime/LICENSE`。安卓和 iPhone 通过浏览器使用，不是原生安装包。

## 阿里云/Linux 部署

已支持 Linux 使用 Node.js 原生 HTTPS 请求天气；配置和逐步说明见 `阿里云服务器部署说明.md`。`阿里云部署包.tar.gz` 可上传到 Ubuntu 服务器，使用 systemd 与 Nginx 提供固定网址，本地 CMD 启动方式保持不变。尚未连接或部署到任何阿里云账号。
